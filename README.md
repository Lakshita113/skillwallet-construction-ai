Multimodal Construction Intelligence Platform

Project Overview

An AI-powered platform for construction site safety, structural crack diagnostics, project planning, valuation, and daily site assistance.

Features

1. Site Safety & PPE Audit – Helps review construction-site images for PPE compliance and potential hazards.
2. Crack Diagnostics – Supports preliminary analysis of visible structural cracks.
3. Planning & Valuation – Provides construction planning and project valuation assistance.
4. Daily Site Assistant – Offers guidance for common construction-site queries.

Technologies Used

- Python
- Streamlit
- Google Gemini API
- GitHub
- Streamlit Community Cloud

How to Run Locally

1. Clone this repository.

2. Install the required dependencies:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "streamlit run app.py"

Deployment

The application is deployed using Streamlit Community Cloud.

Disclaimer

This application is intended for preliminary screening and planning only. Its outputs do not replace professional inspection by a licensed structural engineer or certified safety officer.
